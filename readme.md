## To add the gemini ai api key to vercel environment run the below command and paste the api key 
## create the api key from https://aistudio.google.com/
```bash
vercel env add GEMINI_API_KEY
```

## create the openai key from https://platform.openai.com/settings/organization/api-keys
```bash
vercel env add OPENAI_API_KEY
```

Run the script to test 
```bash
python instant.py
```
